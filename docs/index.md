# Documentation Map

本目录保存人类可读的项目文档、脚本说明和运行手册。

## Responsibilities

| Path            | Responsibility                                |
| --------------- | --------------------------------------------- |
| `README.md`     | 仓库入口、快速命令和文档导航。                |
| `PRODUCT.md`    | 产品上下文、用户、边界、数据原则和版本策略。  |
| `DESIGN.md`     | 注入式 userscript UI 的设计上下文和组件规则。 |
| `docs/`         | 人类可读说明、脚本 runbook、项目约定。        |
| `docs/scripts/` | 具体脚本或本地工具的使用说明。                |
